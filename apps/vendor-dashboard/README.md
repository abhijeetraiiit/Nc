# Vendor Dashboard

Mobile-centric vendor management portal with AI-powered insights.

## Features

- 📊 Real-time sales analytics
- 🤖 AI inventory health predictions
- 📄 One-tap GST invoice generation
- 🎯 Trust Score breakdown
- 📱 Mobile-first dark mode design
- 🔔 Push notifications for urgent actions

## Development

```bash
npm run dev  # Starts on port 3001
```

## AI Features

- Stock optimization suggestions
- Sales trend predictions
- Auto-generated product descriptions
- Dynamic pricing recommendations

## Compliance

- GST invoice generation
- TCS deduction automation
- Warehouse management
- KYC verification workflow
