# Admin Panel

Comprehensive admin control panel for platform management and compliance monitoring.

## Features

- 📊 Platform-wide analytics
- 👤 Vendor approval workflows
- ✅ GI-tag product verification
- ⚖️ Compliance monitoring dashboard
- 🎯 Trust Score algorithm configuration
- 📈 System-wide analytics

## Development

```bash
npm run dev  # Starts on port 3002
```

## Compliance Monitoring

- DPDP Act 2023 compliance
- GST automation status
- Legal Metrology compliance
- Consumer Protection metrics
- FDI Policy verification

## Admin Functions

- Approve/reject vendor applications
- Verify GI-tagged products
- Configure Trust Score weights
- Monitor system health
- Generate compliance reports
