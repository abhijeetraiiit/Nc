# Nc Web App

Customer-facing Next.js 15 application with modern Bento Grid layout and Neubrutalism design.

## Features

- 🎨 Bento Grid landing page
- 🎯 Neubrutalism design system
- 📱 Mobile-first responsive design
- 🚀 Next.js 15 with App Router
- ⚡ Server Components & Partial Prerendering
- 🎭 Framer Motion animations
- 🔍 React Query for data fetching
- 💾 Zustand state management

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## Tech Stack

- **Framework**: Next.js 15
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **State**: Zustand
- **Data Fetching**: React Query
- **Components**: @nc/ui package

## Features Implemented

### Landing Page
- Bento Grid category layout
- Social proof ticker (trending products by city)
- Featured products showcase
- Why Choose Nc section
- Comprehensive footer with compliance info

### Design System
- Neubrutalism theme with bold borders
- Offset shadows (8px 8px)
- High contrast colors
- Modern typography (Inter Variable)

### Compliance
- Grievance Officer contact in footer
- Legal links (Privacy, Terms, etc.)
- Country of Origin display ready
- DPDP-compliant structure
